Pipeboard provides an AI‑powered marketing collaboration platform that automates ad agency workflows, integrates with major ad networks (Google, Meta, Amazon), and offers a Multi‑Channel Platform (MCP) for unified campaign management. The service includes token‑based API access, detailed guides, pricing tiers, and a public status page, enabling developers to programmatically manage advertising assets and analytics.

**Areas:** Advertising · Marketing · AI · Automation · MCP

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for pipeboard-co: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
